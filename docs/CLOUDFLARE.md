# Cloudflare deployment

The current configuration serves both the journal and its private CMS on `blog.thatvetguy.net`, preserving the main portfolio on `www.thatvetguy.net`. Build: `npm run build`. Production deployment: `npx wrangler deploy`. Preview version: `npx wrangler versions upload`. Keep branch `main`, root `/`, and Worker name `blog-thatvetgut-net`.

The Worker entry point is `worker/index.js`. Static assets use `./dist`, the `ASSETS` binding, SPA fallback and `run_worker_first`. Build-time public Firebase variables generate `worker/public-config.js`. This file is ignored by Git, contains no administrative credentials and is generated by every build. Named database and production rules must be configured as described in [ENHANCEMENT-DEPLOYMENT.md](ENHANCEMENT-DEPLOYMENT.md).

Runtime-only changes cannot alter the Vite bundle. Save build variables and trigger a new build/deployment. Preserve the existing authenticated-domain configuration in Firebase.
